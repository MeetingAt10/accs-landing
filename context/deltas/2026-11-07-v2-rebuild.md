# ACCS landing v2 rebuild

Status: implemented on branch `backup/redesign-v2-20261107`. Branch `redesign/v2` holds only the scaffold. Master: this delta.

Rebuild the landing site from a scaffold, without `@meetingat10/design-system`, Tailwind or Motion. Keep the content, routes, anchors, build-time URLs and static export. Only the visual language and the components change.

## Direction

Wayfinding for a college. ACCS is pronounced "access", so the site reads like the signs and route map of a public transit system: where you can go and who handles a concern.

- Ground: Sign Blue `#032E87` for the hero and sign bands, Navy `#172033` for ink, cool paper `#F3F6FB`. In dark mode only the paper sections change; sign bands keep their blue.
- Accent: Signal Yellow `#FFC629` for the primary action and "you are here". Seven line colors exist only to identify the seven workspaces.
- Type: Archivo with its width axis (expanded for signs, condensed for map labels), Atkinson Hyperlegible Next for reading, Atkinson Hyperlegible Mono for references and times.
- Shape: square corners and 45 degree cuts. Only stations are round.
- Signature: the route map. One college account fans out into seven lines, each ending at a workspace. Picking a line shows that workspace's preview.

## Sections

Hero sign with a fixed board of workspace links, route map with working previews (`#sites`), pictogram wall (`#features`), concern route with the adviser bypass (`#guidance`), request staircase (`#workflow`), programs (`#programs`), thread list (`#forum`), departures board (`#events`), final sign, footer. The site has one route. Module and role lists are not on this site; they live on the design system site.
